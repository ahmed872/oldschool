# Smart POS

نظام نقطة بيع (POS) لسطح المكتب، مبني بتصميم أصلي خاص (مش نسخة من أي نظام تاني).

## المميزات
- تسجيل دخول بصلاحيات (مدير / كاشير).
- شاشة كاشير: إضافة منتجات للفاتورة، خصم، ضريبة، طرق دفع.
- إدارة منتجات وفئات (كل فئة ممكن تتحدد كـ "فئة مطبخ" فتظهر أوردراتها في شاشة المطبخ).
- شاشة مطبخ منفصلة (نافذة ثانية) بتتحدث تلقائيًا كل 4 ثواني.
- طباعة الفاتورة على أي طابعة متصلة بالجهاز (طابعة إيصالات أو عادية).
- سجل مبيعات + مرتجعات (إرجاع صنف أو أكثر من فاتورة سابقة مع استرجاع المخزون تلقائيًا).
- تقارير أرباح (المبيعات، التكلفة، صافي الربح، الأكثر مبيعًا) لأي فترة تاريخ.
- إدارة الموظفين (إضافة/إيقاف مستخدمين، كل واحد بصلاحية مدير أو كاشير).
- إعدادات عامة (اسم المتجر، العملة، نسبة الضريبة).
- قاعدة بيانات SQLite مدمجة جوه التطبيق نفسه — **مفيش أي حاجة تانية اليوزر محتاج يثبتها** (لا MySQL ولا أي سيرفر منفصل).

## بيانات الدخول الافتراضية (للتجربة فقط - غيّرها بعدين)
| اسم المستخدم | الرقم السري | الصلاحية |
|---|---|---|
| admin | 1234 | مدير |
| cashier | 1111 | كاشير |

المدير بس هو اللي شايف: المنتجات، التقارير، الموظفين، الإعدادات. الكاشير شايف بس شاشة البيع وسجل المبيعات.

## التشغيل في وضع التطوير
```
npm install
npm start
```

## بناء ملف تثبيت Windows (exe) محليًا
```
npm run dist
```
الناتج هيكون في `dist/` (ملف Setup.exe جاهز للتوزيع).

## التوزيع التلقائي عبر GitHub (الطريقة الموصى بيها)
المشروع فيه GitHub Action جاهز (`.github/workflows/build-release.yml`) بيعمل الآتي تلقائيًا:
1. تعمل تاج (tag) بالشكل `v1.0.0` وتعمله push.
2. GitHub Actions هيشغل بناء كامل على Windows، وينتج ملف exe.
3. الملف هيترفع تلقائيًا كـ **GitHub Release** مرفق بيه.
4. تاخد لينك الـ Release وتبعته لليوزر — يفتح الملف ويثبته على طول، من غير ما ينزل أي حاجة تانية.

مثال لعمل ريليز جديد:
```
git tag v1.0.0
git push origin v1.0.0
```

## هيكل المشروع
```
electron/
  main.js       # العملية الرئيسية - بتفتح النوافذ، تسجيل الدخول، الطباعة، وتربط قاعدة البيانات
  preload.js    # جسر آمن بين الواجهة وقاعدة البيانات
  db.js         # كل منطق قاعدة البيانات (SQLite) - منتجات، مبيعات، مرتجعات، تقارير، مستخدمين
renderer/
  login.html    # شاشة تسجيل الدخول
  index.html    # الشاشة الرئيسية (كاشير + منتجات + مبيعات + تقارير + موظفين + إعدادات)
  kitchen.html  # شاشة المطبخ
  receipt.html  # قالب طباعة الفاتورة
  app.js / login.js / kitchen.js / receipt.js / styles.css
```
